# Ratina Computex2026

* * *

Computex2026我們展示的是結合Digital Human和機器手臂互動的展場互動系統。 在此之上我們設計了一套展場問答的互動流程，讓客人可以親自和機器手臂互動。和去年的取餐系統或是展場互動相比我們優化了其中的步驟並額外設計系統來加強展場互動的體驗。

## 🚀 核心功能

語音辨識 (ASR): 將使用者語音轉換為文字  
智能代理 (LLM Agent): 基於大型語言模型的對話系統  
子Agent (Sub Agent): 多Agent協作系統  
多服務協議適配器 (MCP): 連接並調用多種外部服務和工具  
文字轉語音 (TTS): 將回覆轉換成自然的人聲輸出  
語音轉動畫 (A2F): 將語音轉換為數位🐭的面部表情和動作


## 展場問答互動

為了展現 AI Agent 的互動能力並提升展場參與度，今年我們設計了一套問答小遊戲流程：Agent 會主動跳出選項讓使用者選擇（例如是否參加遊戲、想了解哪類產品），透過預先設計好的互動路徑，使用者在遊玩過程中不會遇到「不知道該問什麼」的空窗期。同時把對話範圍收斂在預設流程內，也能降低 LLM 產生幻覺、答非所問的機率——是兼顧互動性與穩定性的做法。

## 功能升級

### 框架升級

- **推論引擎替換：以 vLLM 取代 Ollama**
  - 提升模型推論速度

- **設計 Sub-Agent 展場互動系統**
  - 建立 Main-Agent / Sub-Agent 架構
  - 依任務類型分派給對應的 Sub-Agent，讓各 Agent 專注於自身擅長的內容
  - 任務分為
    - 展場互動Sub-Agent
      - 管理問答小遊戲
      - 呼叫手臂動作
      - 友善有精神的互動方式
    - 公司產品問答Sub-Agent
      - 調用公司產品資料庫
      - 分析使用場景推薦適合產品
      - 專業問答語氣

- **設計資料庫問答系統**
  - 透過 MCP 存取資料庫中的資料
  - 讓 Agent 自主查詢資料庫，以取得更精準、更完整的回覆

- **名片內容擷取系統**
  - 透過 MCP 擷取鏡頭畫面，交由 VLM 辨識並擷取名片資訊
  - 同時支援展場 badge 與名片兩種格式

### 其餘升級

- **優化啟動速度**：將開機後可用時間從 5～7 分鐘縮短至 2 分鐘
- **優化手臂協作**：手臂動作時Digital Human會同步回答，不用乾等手臂動作。

## 🏅 我的貢獻

### 系統架構設計
- 設計 Main-Agent / Sub-Agent 多代理協作架構，依任務類型分派給展場互動、產品問答等 Sub-Agent

### 展場互動流程設計
